                         cdsapi retrieve of 10m u/v from reanalysis-era5-single-levels;
                         sigma-free: speed=sqrt(u^2+v^2), dir=atan2(-u,-v) (meteorological FROM);
                         lazy imports (cdsapi/xarray) so file mode needs neither.
  Configuration        : config.WIND_SOURCE ("file" default | "era5");
                         ERA5_DATASET, ERA5_VARIABLES, ERA5_CACHE_DIR. main.py uses the source
                         and LOGS provenance (not injected into the scored response).
  Cache                : <repo>/data/cache/era5/era5_<key>.nc; key = sha256(dataset, area N/W/S/E,
                         hourly timestamps, variables). Validated (readable, u/v/lat/lon/time vars,
                         time-range covered) before reuse; corrupt cache discarded + re-fetched.
  Fallback             : ERA5 failure (no creds / unreachable / corrupt) -> FileWindSource with
                         provenance source="FILE_FALLBACK" and reason logged. Never crashes;
                         never presents fixture wind as ERA5.
